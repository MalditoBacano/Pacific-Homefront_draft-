## Required Images (Already Configured!)

### 1. **logo.png** ✅
**This is your main logo - already set up in the navbar and footer!**
- **File name:** `logo.png` (or `logo.svg` for best quality)
- **Recommended size:** Width 150-250px, Height 40-60px
- **Format:** PNG with transparent background (or SVG)
- **Usage:** Navigation bar (top) and footer
- **Notes:**
  - Logo will be white in the footer (automatically inverted)
  - Responsive sizing already configured
  - Just drop the file here and refresh your browser!

## Quick Image Creation Tips

### Using Canva (Free)
1. Go to canva.com
2. For favicon: Create 512x512px design
3. For OG image: Use "Facebook Post" template (1200x630px)
4. Use brand colors: #2563eb (blue) and #06b6d4 (cyan)
5. Download as PNG (favicon) or JPG (og-image)

### Using Figma (Free)
1. Create new design with required dimensions
2. Add Pacific Homefront branding
3. Export as PNG/JPG

### Stock Photos
- **Unsplash:** unsplash.com (free high-quality images)
- **Pexels:** pexels.com (free stock photos)
- Search terms: "modern house california", "property management", "real estate"

## Implementation

Once you have the images:

1. Place them in this `/assets` folder
2. The HTML already references:
   - `assets/favicon.png`
   - `assets/og-image.jpg`
3. No code changes needed - just add the files!

## Fallback

If you don't have images yet, the website will still function perfectly. The images enhance SEO and social sharing but aren't required for the site to work.
